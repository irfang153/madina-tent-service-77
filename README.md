# Madina Tent Service

یہ مدینہ ٹینٹ سروس کے لیے Flutter Android app کا نیا source package ہے۔

اہم خصوصیات:
- ٹینٹ، کرسیاں، میزیں، پلیٹیں، جگ، دیگیں، دریاں، دسترخوان، پنکھے اور لائٹس
- ہر سامان کی کرایہ قیمت
- دستیاب مقدار
- کرایہ کے لیے مقدار منتخب کرنا
- کل کرایہ خودکار حساب
- رسید کا نظام شامل نہیں

یہ package جان بوجھ کر پرانے Flutter/Gradle project کو استعمال نہیں کرتا۔ GitHub Actions میں تازہ Flutter project بنایا جا سکتا ہے اور اس source کو اس میں رکھا جا سکتا ہے۔
